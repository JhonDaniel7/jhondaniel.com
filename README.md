# Jhon Daniel Portfolio

Base iniziale del progetto portfolio.

## Stack

- Angular 20
- Bootstrap 5.3.8
- SCSS
- Standalone Components
- Strict TypeScript

## Avvio

```bash
npm install
npm start
```

Apri `http://localhost:4200`.

## Build produzione

```bash
npm run build
```

Bootstrap è configurato globalmente in `angular.json` (CSS + bundle JS). Lo stile personalizzato del sito va in `src/styles.scss` e negli SCSS dei componenti.
